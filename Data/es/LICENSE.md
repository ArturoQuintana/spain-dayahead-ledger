# Data licence — Spain (ES)

Price data in this directory is day-ahead wholesale electricity prices for Spain,
sourced from **Red Eléctrica de España (REE)** via the public `apidatos.ree.es`
API (cross-checked against the token-based ESIOS route, `api.esios.ree.es`).

- Source: https://www.ree.es/ · https://apidatos.ree.es/
- Terms: REE public / open data — see REE's data terms for the authoritative
  conditions.
- Required attribution: **Red Eléctrica de España (REE)**.

Ledger figures here are **derived** metrics (settlement of a simulated
1 MW / 2 MWh battery against these prices), provided by Talea. The authoritative
licence conditions are those published by the source. The Talea code is licensed
separately — see `/LICENSE`.
