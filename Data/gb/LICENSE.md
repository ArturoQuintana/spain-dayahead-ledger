# Data licence — Great Britain (GB)

Price data in this directory is GB day-ahead **Market Index** price, sourced from
**Elexon** via the **BMRS Insights** open-data API (provider APXMIDP).

- Source: https://www.elexon.co.uk/ · https://bmrs.elexon.co.uk/ ·
  https://data.elexon.co.uk/
- Terms: Elexon **Insights open data** — see Elexon's data licence / terms of use
  for the authoritative conditions permitting access, modification, and
  redistribution.
- Required attribution: **Elexon / BMRS**.

Ledger figures here are **derived** metrics (settlement of a simulated
1 MW / 2 MWh battery against these prices), provided by Talea. The authoritative
licence conditions are those published by the source. The Talea code is licensed
separately — see `/LICENSE`.
