# Data licence — Germany (DE)

Price data in this directory is day-ahead wholesale electricity prices for the
**DE-LU** bidding zone, sourced from **SMARD.de**, the electricity market data
platform of the **Bundesnetzagentur** (German Federal Network Agency).

- Source: https://www.smard.de/
- Licence: **Creative Commons Attribution 4.0 International (CC BY 4.0)**
  — https://creativecommons.org/licenses/by/4.0/
- Required attribution: **Bundesnetzagentur | SMARD.de**.

Ledger figures here are **derived** metrics (settlement of a simulated
1 MW / 2 MWh battery against these prices), provided by Talea. CC BY 4.0 permits
redistribution with attribution; the authoritative conditions are those published
by the source. The Talea code is licensed separately — see `/LICENSE`.
