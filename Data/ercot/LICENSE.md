# Data licence — ERCOT (Texas)

Price data in this directory is ERCOT **Day-Ahead Market Settlement Point Prices**
for hub **HB_NORTH**, sourced from the **ERCOT MIS** public report **NP4-190**.

- Source: https://www.ercot.com/ · https://mis.ercot.com/
- Terms: ERCOT **public data** (the NP4-190 public/redistributable report) — see
  ERCOT's terms of use for the authoritative conditions.
- Required attribution: **ERCOT**.

Ledger figures here are **derived** metrics (settlement of a simulated
1 MW / 2 MWh battery against these prices), provided by Talea. The authoritative
licence conditions are those published by the source. The Talea code is licensed
separately — see `/LICENSE`.
